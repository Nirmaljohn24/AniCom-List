# Animated E-Commerce List Page

This project is an interactive e-commerce list page that enhances the user experience with engaging animations and a responsive design.

## Features

### 1. Product Listing Grid
- Products are displayed in a responsive grid layout.
- Each product card includes:
  - Image
  - Name
  - Price
  - "Add to Cart" button

### 2. Animations
- **Hover Effect**: 
  - Product cards scale up slightly with a shadow effect on hover.
- **Loading Animation**: 
  - A spinner  loader is displayed while the page is loading.
- **Add to Cart Button Animation**:
  - Click ripple effect on the button.
  - Subtle cart icon animation when an item is added.
- **Filter/Sort Animation**:
  - Smooth transitions when applying filters or sorting options.

### 3. Filters and Sorting
- A filter bar includes options such as category and price range.
- Sorting options like "Price: Low to High" are implemented with smooth animations.

### 4. Cart Notification
- A toast notification or floating animation is displayed when a product is added to the cart.

### 5. Bonus Features
- **Scroll-to-Top Button**:
  - A smooth scroll-to-top button appears when the user scrolls down.
- **Use of Dummy Product Data from a JS File**:
  - Product data is sourced from an external JavaScript file, ensuring a dynamic and maintainable structure for the product listing.
  
## Technical Requirements
- **Technologies Used**:
  - HTML
  - CSS (Tailwind)
  - JavaScript ( React.js for dynamic behavior)
- **Animations**:
  - Implemented using CSS transitions, keyframes, and optional GSAP for advanced effects.
